# Surse pentru imagini

## Capturi de terminal (folderul acesta)

Fișierele `term-*.png` sunt capturi reale făcute într-un terminal `xterm` pe Ubuntu 24.04, cu un utilizator `student`. Comenzile și mesajele sunt exact cele afișate de sistem. Singura ajustare e promptul (`student@fmi`), setat pentru claritate.

| Fișier | Ce arată | Slide |
| --- | --- | --- |
| `term-cover.png` | `whoami`, `pwd`, `echo`, `ls` | copertă |
| `term-start.png` | `whoami`, `pwd`, `ls`, `cd`, `ls -la` | Terminale |
| `term-glob.png` | măștile `*.c`, `tema?.txt`, `lab[12].c` | Măști |
| `term-path.png` | `command not found`, `./program`, `echo $PATH`, `which` | $PATH |
| `term-gcc.png` | `make`, coduri de ieșire cu `echo $?` | Rulare |
| `term-erori.png` | erori frecvente | Capcane |
