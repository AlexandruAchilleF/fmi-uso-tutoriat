3 · Copierea, pas cu pas

read spune câți octeți a citit. 0 = gata.

exercitiu.cbucla de copiere
fd_sursa = open("mesaj.txt", O_RDONLY); // 3
fd_dest = open("copie.txt", O_WRONLY|O_CREAT|O_TRUNC, 0644);
while ((n = read(fd_sursa, buf, 64)) > 0) {
write(fd_dest, buf, n); // n, nu 64!
total += n;
}
close(fd_sursa); close(fd_dest);

Exercițiul de azi

Un „mini cp” doar cu apeluri sistem

./exercitiu <sursa> <destinatie> copiază un fișier în altul. Merge la fel pe Linux și pe Mac.

1

Exact două argumente.Altfel: Utilizare: ... pe stderr și cod 1.

2

Sursa cu O_RDONLY.La -1: perror(argv[1]) și cod 1.

3

Destinația cu O_WRONLY | O_CREAT | O_TRUNC, 0644.La eroare, închide întâi sursa.

4

Bucla read / write, câte 64 de octeți.Scrie n octeți, cât a citit read.
